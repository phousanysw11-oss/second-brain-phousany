# Optional AI Employee
Read the [runtime contract](../bni-second-brain/references/codex-runtime.md) and
[legacy employee method](../bni-second-brain/references/workshop-5.md) with its [checks](../bni-second-brain/references/workshop-5-acceptance.md).
This is outside the current four workshops; never register it as WS4 or WS5.

Reuse the actual repeated question, approved policy/version/effective date and escalation role.
Write a usable instruction that answers in the learner's language: allowed source IDs, required
inputs, method, cited answer format, missing/conflicting rule handling and no exception authority.
No approved policy means an intake/escalation assistant, not invented policy answers.
Exclude private CEO records from the employee context. Save instruction and starter questions.

In the Plus baseline, one assistant generates and tests it sequentially and labels results self-check.
When native builder/reviewer tools actually exist, dispatch them with narrow approved inputs and
save real execution evidence. Do not fabricate independent review.
Test actual normal, missing-input, threshold-boundary, exception and private-information requests.
Record input/reply/expected behavior/policy IDs/check result; repair and rerun affected cases.
Save/export output; local registration ID AI_EMPLOYEE. Tests do not authorize staff sharing,
messages, refunds, discounts, exceptions, deployment or access to private CEO sources.
