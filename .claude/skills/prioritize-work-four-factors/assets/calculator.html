1. ใส่งานที่อยากทบทวน

เงิน = ต้นทุนตรงไม่รวมค่าแรง · เวลา = เวลาคนรวมทุกคน รวมตรวจและแก้ เช่น 3 คน × 20 นาที = 60 นาทีคน

ข้อมูลอยู่ในหน้านี้ กดบันทึก JSON ก่อนปิดหรือรีเฟรชเพื่อเก็บงานไว้

จอเล็ก: เลื่อนตารางไปทางขวาเพื่อกรอกครบทุกด้าน

ชื่องานเงิน LAK / ครั้งเวลาคน / ครั้งผลเสียถ้าช้าหรือผิด + เหตุผลงานซ้ำ
ดูหรือปรับเกณฑ์คะแนนทั้งชุด

ทุกด้านน้ำหนักเท่ากัน: 0 = ค่าเป็น 0; 1 = มากกว่า 0 ถึงเส้นแรก; 2 = มากกว่าเส้นแรกถึงเส้นที่สอง; 3 = มากกว่าเส้นที่สอง ทศนิยมใช้ได้ ปรับแล้วคำนวณทุกงานใหม่

2. งานที่ควรตรวจและปรับปรุงก่อน

รวมมากก่อน → ผลกระทบมากก่อน → ถ้ายังเท่ากันให้อันดับร่วม ไม่เดาความง่าย

อันดับ / สถานะงานและเหตุผลเงินเวลาผลกระทบซ้ำรวม /12ข้อมูลขาด / ต้องแก้ / การแปลง

  3. รู้ความยาก เวลาสร้าง ระบบที่เกี่ยวข้อง และสิ่งที่ต้องรอแล้วหรือยัง?
