# เครื่องคำนวณภาษาไทย

เปิด `assets/calculator.html` ใน browser โดยตรง ไม่ใช้ server หรืออินเทอร์เน็ต เริ่มจากธุรกิจและช่วงอ้างอิงเดียว แล้วกรอกชื่อและข้อมูล 4 ด้าน ตัวอย่างเป็นข้อมูลสมมติทั้งหมด

เงินเป็น LAK/ครั้งไม่รวมค่าแรง เวลาเป็นนาทีคน/ครั้งรวมทุกคนและตรวจแก้ เช่น 3 คน × 20 นาที = 60 นาทีคน เลือกชั่วโมงคนเพื่อให้ระบบคูณ 60 ได้ ระบบไม่คูณจำนวนคนให้อัตโนมัติ

ความถี่เลือกฐานเดียว: ครั้ง/เดือน; ครั้ง/วันทำงานพร้อมวันทำงานจริงของงานในเดือนนั้น (จำนวนเต็ม 0–31 ไม่เดา 30); หรือครั้ง/ปีเพื่อเฉลี่ยหาร 12 เศษครั้งต่อเดือนได้ ห้ามใส่ยอดรวมหลายเดือนเป็นครั้ง/เดือน

ช่องตัวเลขรับเลขทศนิยมไม่มี comma คั่นหลัก หรือ ?/ว่างสำหรับยังไม่ทราบ 0 ต้องยืนยันว่าไม่มี ทุกระดับผลกระทบต้องมีเหตุผล

รายละเอียดใต้ชื่องานเปิดเพิ่มนิยามค่าใช้จ่ายและแหล่งข้อมูลได้ ค่าเริ่มต้นของนิยามเป็นเพียง “ต้นทุนตรงไม่รวมค่าแรง ตามค่าที่กรอก” ยังไม่ใช่รายการต้นทุนที่ตรวจแล้ว ถ้ายังไม่ใส่แหล่งข้อมูลจะแสดงคำเตือนว่าไม่ได้ยืนยันค่า

บันทึก JSON ก่อนปิด/รีเฟรช หน้าไม่บันทึกให้อัตโนมัติ JSON ใช้ [รูปแบบสกิลเดิม](MODEL_TH.md) เปิดด้วยหน้า HTML หรือ scripts/score.py ได้เหมือนกัน เมื่อส่งออก ชั่วโมงถูกแปลงเป็นนาทีคน เมื่อนำกลับมาเปิดแสดงนาทีคน จึงคงเวลารวมเดิม ข้อมูลผิดเก็บไว้แก้ต่อได้ ไม่มีคะแนนรวม/อันดับจนถูกและครบ

ปรับเกณฑ์เฉพาะระดับชุดพร้อมเหตุผล คำนวณใหม่ทุกแถว น้ำหนักเท่ากัน

คะแนนรวมและผลกระทบเท่ากันให้อันดับร่วม หากไฟล์มี fix_minutes, ease_evidence, ease_basis ของทุกงานในกลุ่มเสมอและฐานเดียวกัน จะใช้เวลาแก้น้อยก่อนตามกติกาเดิม หลักฐานเหล่านี้เป็นข้อมูลที่ผู้จัดทำส่งมา ไม่ใช่สิ่งที่เครื่องคำนวณตรวจให้ ต้องตรวจ C/E ก่อนลงมือจริง

สำหรับผู้พัฒนา: scripts/score.cjs รับรูปแบบภายในหน้าผ่าน audit(); fromCanonical()/toCanonical() แปลง JSON สกิลเดิม ใช้ Python ตรวจเทียบ Node scripts/build.cjs ฝัง engine ลง HTML ไฟล์เดียว Node scripts/test-score.cjs ทดสอบขอบคะแนนและแปลงข้อมูล ชุดตรวจเทียบ Python และ browser อยู่ในแพ็กเกจตรวจรับข้าง ZIP
