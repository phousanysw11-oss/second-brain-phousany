# Delegation

Read [the shared local runtime contract](../bni-second-brain/references/codex-runtime.md) before work.
Reuse `data/state.json` and the selected company's accessible files; save outputs under `work/ceo/`.

Use the actual requested outcome, recipient role, deadline and authority already provided.
Write a brief another person can execute: purpose, deliverable, one proposed or confirmed owner, source inputs,
scope/limits, decision rights, next step, deadline if supplied, check-in trigger and observable done criteria.
Separate ownership proposal from the person's acceptance. No fabricated staffing commitment or deadline.
Make the human checkpoint match the risk; routine execution should not need repeated CEO approval.
Save the ready-to-review brief and optionally a proposed task through authoritative state. Do not send it or assign externally
unless the user explicitly requests that action and recipient within the current scope.
