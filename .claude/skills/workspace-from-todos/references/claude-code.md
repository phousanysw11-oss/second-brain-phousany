# ใช้กับ Claude Code

ใช้ `workspace-from-todos` เพียง skill เดียวเพื่อเปลี่ยนรายการงานเป็น workspace ในเครื่อง เมื่อผู้เรียนต้องการเผยแพร่จึงเลือกบริการ hosting ที่ใช้ได้และอนุญาตให้ดำเนินการ

## ติดตั้งในโปรเจกต์ของตัวเอง

ต้องมี Claude Code ที่ใช้งานได้ และ Node.js สำหรับ helper ของแพ็กเกจ เปิด terminal ในโฟลเดอร์ที่แตก ZIP ซึ่งมี `install.mjs` แล้วรัน:

```sh
node ./install.mjs claude ../my-project
```

เปลี่ยน `../my-project` เป็นโฟลเดอร์โปรเจกต์ของตัวเอง ตัวติดตั้งจะหยุดถ้ามี skill ชื่อนี้อยู่แล้ว ตรวจว่ามีไฟล์:

```text
.claude/skills/workspace-from-todos/SKILL.md
```

เปิด Claude Code ที่โปรเจกต์นั้น ตำแหน่ง `.claude/skills/` เป็น project skill และเรียกด้วย `/workspace-from-todos` หากเพิ่มโฟลเดอร์ skills เป็นครั้งแรกแล้วไม่ปรากฏ ให้เริ่ม session ใหม่ ดู [เอกสาร Claude Code skills](https://code.claude.com/docs/en/skills)

## เริ่มใช้งาน

```text
/workspace-from-todos สร้าง workspace ส่วนตัวจากรายการงานด้านล่าง
ให้ใช้ในเครื่องก่อน มีปุ่มไทย/English และรักษาข้อความงานเดิม
ถามเฉพาะข้อมูลที่จำเป็นต่อการจัดงาน

[วางรายการงานของตัวเอง]
```

Claude จะอ่าน skill ใช้ template และรัน Node helper ที่แนบมา โดยไม่ต้องพึ่ง Sites หากต้องการสร้าง starter เปล่าด้วยมือ ให้เปิด terminal ที่โฟลเดอร์โปรเจกต์แล้วรัน:

```sh
node ./.claude/skills/workspace-from-todos/scripts/create-workspace.mjs ./my-workspace
cd ./my-workspace
npm run check
npm start
```

`my-workspace` ต้องยังไม่มีอยู่ เปิด URL ที่ server แสดง ใช้ URL เดิมเมื่อกลับมาทำงาน และกด `Ctrl+C` เพื่อหยุด server การใช้ Node helper นี้เป็นวิธีของแพ็กเกจ ไม่ใช่คำสั่ง built-in ของ Claude Code

ก่อนใช้งานจริง ให้ลองเปลี่ยนไทย/English เพิ่มและแก้งาน โหลดหน้าใหม่ แล้ว export และ import ไฟล์สำรอง ตรวจว่าข้อความงานเดิมและข้อมูลสำคัญยังครบ

## เก็บข้อมูลของตัวเอง

เก็บ JSON งาน/โน้ตจริงไว้นอกโฟลเดอร์เว็บทั้งโฟลเดอร์ เช่น `../workspace-data/tasks.json` ไม่ใส่ไว้ใน source, template หรือ `dist/` และไม่ commit/upload ไฟล์นั้น นำเข้าผ่านปุ่มในเบราว์เซอร์หลังเปิดเว็บ

starter เก็บข้อมูลใน browser storage ของ URL และ browser profile นั้น การเปลี่ยนเครื่อง เบราว์เซอร์ หรือ URL ต้อง export แล้ว import เอง การล้างข้อมูลเบราว์เซอร์อาจลบงาน จึงควรมีไฟล์สำรอง ข้อความที่ส่งให้ AI ยังเป็นส่วนหนึ่งของแชตที่ใช้สร้างงาน

## เมื่อต้องการเผยแพร่

ให้ผู้เรียนระบุว่าจะใช้บริการใดและให้ใครเข้าถึง แล้วตรวจเครื่องมือ การเชื่อมต่อ และสิทธิ์ของบริการนั้นก่อนทำงาน การติดตั้ง skill นี้ไม่ได้ติดตั้งผู้ให้บริการ hosting และไม่ได้ย้ายบัญชีหรือข้อมูลจาก Codex ให้อัตโนมัติ

จากโฟลเดอร์ `my-workspace` ใช้:

```sh
npm run build
```

ผลลัพธ์ `dist/` มีเฉพาะ `index.html`, `styles.css`, `app.js` ให้ใช้โฟลเดอร์นี้เป็น public output ของบริการที่ผู้เรียนเลือก ทำตามเอกสารและเครื่องมือปัจจุบันของบริการนั้น และตรวจสิทธิ์การดูเว็บก่อนเผยแพร่ ไม่อัปโหลดโฟลเดอร์ข้อมูลจริงหรือแพ็กเกจ skill ทั้งชุด

ถ้ายังไม่มีบริการหรือสิทธิ์ที่พร้อม ให้คง workspace ที่ใช้งานในเครื่องได้และบอกสิ่งที่ต้องเชื่อมต่อ รายงาน URL เผยแพร่เฉพาะที่บริการคืนมาหลังทำสำเร็จ การเผยแพร่ starter ไม่เพิ่ม cloud sync, ฐานข้อมูลร่วม หรือระบบเตือนเบื้องหลัง
