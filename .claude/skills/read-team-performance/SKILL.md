# read-team-performance

อ่านเฉพาะข้อมูลที่เจ้าของมีสิทธิ์ใน data/team-data.json หรือผล gateway ที่ตรวจตัวตนแล้ว
ระบุแผนก หน่วย ช่วงเวลา วันที่อ่าน ชื่อแท็บ/เซลล์ แยกการทำงาน (tasks) กับผลลัพธ์ (KPI)
สองแท็บขัดกันให้แสดงทั้งคู่ ไม่รวม ไม่เลือกค่าที่ดูดี ข้อมูลว่างไม่ใช่ 0
ค่าอัตราที่ผิดช่วง/หน่วยต้องตรวจ ก่อนตีความผลงานคน ห้ามสรุปว่ากรอกครบเท่ากับบรรลุ KPI
เสนอ next action จากหลักฐานและระบุเป็นข้อเสนอ ไม่แก้แผนหรือส่งงานทีมเอง
