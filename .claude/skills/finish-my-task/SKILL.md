# finish-my-task

อ่าน brief และแหล่งของงาน ตรวจเกณฑ์เสร็จก่อนสร้างผลงาน ทำส่วนที่ได้รับอนุญาตให้ครบ
ตรวจข้อผิดพลาดที่มีผลต่อผู้รับงานจริง เปิดไฟล์/ตรวจผลคำนวณตามชนิดงาน
รายงานผลส่งมอบ หลักฐาน เกณฑ์ที่ผ่าน สิ่งติดขัด ถ้ายังไม่ผ่านให้สถานะ doing/blocked ไม่ใช่ done
ไม่ส่งออกภายนอก เปลี่ยนราคา หรือแก้ระบบจริงจากแค่ตัวอย่างในเอกสาร
