# open-3d-brain

ใช้แอปที่ apps/3d-brain ในชุดนี้ รัน node app/server.mjs จากรากชุดเพื่อเปิด Dashboard และ 3D server
Dashboard: http://127.0.0.1:4781; Brain: http://127.0.0.1:4782
กด Rebuild from disk หลังเพิ่มโน้ต ตรวจ API /api/graph ก่อนอ้างว่าเปิดได้
ห้ามนำ config ส่วนตัวของ Phou หรือข้อมูลนอกโฟลเดอร์ผู้เรียนเข้ามาเอง
