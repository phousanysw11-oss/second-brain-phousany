# Decision review

Read [the shared local runtime contract](../bni-second-brain/references/codex-runtime.md) before work.
Reuse `data/state.json` and the selected company's accessible files; save outputs under `work/ceo/`.

Read the authoritative saved decision and the CEO's actual wording. Distinguish proposal, approved choice and executed action.
Recover original success criteria, assumptions, expected result, owner, review date and stop/change trigger when supplied.
Compare current evidence with that baseline using compatible periods/definitions. Do not judge decision quality solely by hindsight.
State which assumption held, failed or remains untested; consider delay, continue, stop and a smaller test where meaningful.
Return recommendation, trade-offs, evidence that would change it and one next action. Mark suggested owners/dates as proposed.
Only record a changed decision when the CEO actually states one; preserve its earlier evidence/history rather than overwrite it.
