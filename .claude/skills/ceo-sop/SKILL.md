# SOP

Read [the shared local runtime contract](../bni-second-brain/references/codex-runtime.md) before work.
Reuse `data/state.json` and the selected company's accessible files; save outputs under `work/ceo/`.

Start from the actual process evidence or knowledgeable worker's account; preserve unknown steps.
Capture trigger, inputs, owner, numbered actions, decision points, output, quality check, exception/escalation and source version.
Use only approved policies as authority. A proposed improvement must be separate from current observed practice.
Make a short execution checklist from the SOP, not a duplicate narrative. Include a worked permitted example and an exception.
Walk through supplied normal/missing-input/exception evidence; document where another person would get stuck. Use a real Evidence Reviewer if available; otherwise label this a single-assistant self-check.
Save draft SOP plus checklist, source links and unresolved verification needs. Do not claim team adoption or publish it as approved policy.
