# Start your Second Brain

Use [README.md](README.md) as the entry point and paste [INSTALL_MESSAGE.txt](INSTALL_MESSAGE.txt).
Its single INSTALL.md URL locates the correct package and installer. You do not need two links or two installations.

Create or choose a folder → open it locally in Codex or Claude Code → paste the message → choose onboarding.

- **Quick start, recommended:** confirm the business, desired result and first source, then begin.
- **Guided:** answer one relevant question at a time.
- **Use my files:** select sources, let the AI read them, then resolve only important gaps.
- **Later:** retain deferred setup and start ordinary work.

Saved answers are reused. Skip, pause or switch modes at any point.
Read [onboarding details](docs/ONBOARDING.md) and [the CEO start guide](CEO_START_TH.md) for the workshops.

If a skill is absent from the menu, reopen a chat in the same folder or ask the AI to read this project's onboard SKILL.md directly.
Browser-only chat cannot install local project skills/roles. The actual session's available tools, not its subscription label, determine which steps can run.
See [HELP.md](HELP.md) for recovery, offline installation and capability limits.
