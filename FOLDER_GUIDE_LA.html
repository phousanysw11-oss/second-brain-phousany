Folder & File Guide

Folder ເກັບໄຟລ໌. ໄຟລ໌ .md ແມ່ນເອກະສານຂໍ້ຄວາມ Markdown ທີ່ຄົນແລະ AI ອ່ານໄດ້. ເສັ້ນກິ່ງໃນຮູບບອກວ່າໄຟລ໌ຢູ່ບ່ອນໃດ.

MY_SECOND_BRAIN/
├─ README.md
├─ AGENTS.md
├─ CLAUDE.md
├─ context/
│  └─ me.md
├─ work/
│  └─ tasks.md
├─ data/
│  └─ state.json
├─ llm-wiki/
│  ├─ AGENTS.md
│  ├─ raw/
│  └─ wiki/
│     └─ index.md
├─ .agents/skills/
│  ├─ onboard/ ... 3d-brain/
│  └─ workspace-from-todos/
│     ├─ SKILL.md
│     ├─ references/
│     ├─ scripts/
│     └─ assets/template/
├─ .claude/skills/  [same skills]
├─ app/
├─ apps/3d-brain/
└─ fonts/

ນີ້ແມ່ນເສັ້ນທາງຫຼັກ; ບາງລາຍການໃນ Skill ຖືກຫຍໍ້ເພື່ອໃຫ້ອ່ານງ່າຍ.

Folder / FileMeaning
MY_SECOND_BRAIN/ບ່ອນເກັບລະບົບວຽກຂອງທ່ານ
README.mdຄູ່ມືເລີ່ມຕົ້ນສຳລັບຄົນ
AGENTS.mdກະຕິກາແລະທາງໄປອ່ານໄຟລ໌ສຳລັບ Codex
CLAUDE.mdກະຕິກາດຽວກັນສຳລັບ Claude Code
context/ຂໍ້ມູນຊ່ວຍໃຫ້ AI ເຂົ້າໃຈວຽກ
context/me.mdໜ້າທີ່ ເປົ້າໝາຍ ແລະ ຂໍ້ຈຳກັດຂອງທ່ານ
work/ເອກະສານທີ່ກ່ຽວກັບວຽກ
work/tasks.mdລາຍການວຽກທີ່ Dashboard ຂຽນໃຫ້ອ່ານ
data/state.jsonຂໍ້ມູນຫຼັກຂອງ Dashboard; ແກ້ຜ່ານແອັບ
llm-wiki/ຄັງຄວາມຮູ້ທີ່ AI ຊ່ວຍຈັດ
llm-wiki/AGENTS.mdຄູ່ມືການນຳເຂົ້າແລະກວດ Wiki
llm-wiki/raw/ຕົ້ນສະບັບທີ່ເກັບໄວ້ອ້າງອີງ
llm-wiki/wiki/ບົດສະຫຼຸບທີ່ເຊື່ອມກັບຕົ້ນສະບັບ
llm-wiki/wiki/index.mdສາລະບານຫາຫົວຂໍ້
.agents/skills/Skills ສຳລັບ Codex
.claude/skills/Skills ສຳລັບ Claude Code
SKILL.mdຄູ່ມືບອກເວລາໃຊ້ ຂັ້ນຕອນ ແລະ ເກນກວດຂອງ Skill
references/ເອກະສານອ້າງອີງຂອງ Skill ທີ່ມີໄວ້
scripts/ໂປຣແກຣມຊ່ວຍເຮັດບາງຂັ້ນຕອນຂອງ Skill
assets/ແມ່ແບບແລະໄຟລ໌ປະກອບຂອງ Skill
app/ໂປຣແກຣມ Dashboard ຫຼັກ
apps/3d-brain/ໂປຣແກຣມແຜນທີ່ຄວາມຮູ້
fonts/Phetsarath ແລະ ໃບອະນຸຍາດ
OPEN_WINDOWS.cmdເປີດແອັບໃນ Windows
OPEN_MAC.commandເປີດແອັບໃນ Mac
CHECK_WINDOWS.cmd / CHECK_MAC.commandກວດ Node.js ແລະ ໄຟລ໌ກ່ອນໃຊ້

ຊື່ທີ່ເລີ່ມດ້ວຍ . ອາດຖືກເຊື່ອງໃນເຄື່ອງ. ໃນ Mac ກົດ Command+Shift+. ເພື່ອສະແດງ. ຢ່າຄັດລອກສະເພາະໄຟລ໌ທີ່ເຫັນ; ໃຫ້ແຕກ ZIP ທັງໝົດ.
