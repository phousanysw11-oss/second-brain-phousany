# ผลตรวจรุ่นรวมเครื่องคำนวณ

ตรวจเมื่อ 2026-09-12 ใน saved Second Brain ไม่ใช่การทดสอบข้อมูลบริษัทจริง

- ใช้ชื่อเดียว `prioritize-work-four-factors` นำสกิลเดิม 9 ไฟล์จากงานก่อนหน้ามาต่อยอด เก็บ Python และตารางเดิม เพิ่ม HTML สำหรับผู้ใช้ไม่เขียนโค้ด ไม่ติดตั้ง global เพิ่ม
- ตัวอย่างสมมติที่อนุมัติ: แก้คำสั่งซื้อผิด 10, กรอกข้อมูลซ้ำ 7, รายงานภายใน 4
- Python unittest เดิม 25 methods ผ่าน แก้ `?` เป็น missing และแสดง `?` ในตารางแทนขีด
- JavaScript 126 assertions ผ่าน ครอบคลุมศูนย์ ตรงขอบ ก่อน/หลังขอบ เศษครั้ง ข้อมูลขาด/ผิด สกุลเงิน/ธุรกิจ/ช่วงไม่ตรง แปลงชั่วโมง วัน ปี งานไม่เกิด เกณฑ์ปรับทั้งชุด และอันดับร่วม/หลักฐานความง่าย
- เปรียบเทียบ Python กับ JavaScript 91 ชุดข้อมูล ผ่านในคะแนนรวม อันดับ และสถานะ รวมตัวอย่าง ขอบ/เศษส่วน missing/invalid และกลุ่มเสมอ
- Playwright เปิด HTML ผ่าน file URL แบบ headless: กรอกตัวอย่าง, แก้ ?/ค่าติดลบ/ความถี่ 0, แปลงชั่วโมงและรายวัน, บันทึก JSON, รันไฟล์ที่ดาวน์โหลดกับ Python, reload และเปิดคืน, เกณฑ์ผิด/คืนค่าเริ่มต้น, เพิ่ม/ลบแถว ผ่าน ไม่มี JavaScript page errors
- ตรวจภาพ desktop 1440 px และ mobile 390 px ตารางบนมือถือเลื่อนได้ในกรอบ ไม่ล้นทั้งหน้า การตรวจภาพพบช่องวันทำงานแสดงบนรายเดือน จึงแก้ CSS hidden และเพิ่ม assertion ตรวจว่าซ่อนจริงก่อนส่งมอบ
- HTML ฝัง engine จาก score.cjs โดยตรง ชุดทดสอบตรวจว่า engine ในไฟล์สร้างตรงกับ source ไม่มี server หรือบริการภายนอกในการใช้งาน

หลักฐานภาพ/ชุด integration/ผล JSON อยู่ใน `docs/skill-packages/verification-four-factors/` จากราก saved Second Brain (locator สำหรับตรวจรับ ไม่ใช่ dependency ของ skill ZIP)

ขอบเขต: ยังไม่ทดสอบการเรียกสกิลอัตโนมัติใน session ใหม่ หรือให้ทีมใช้งานจริง ผลนี้ไม่รับรองความเหมาะสมของเกณฑ์กับทุกงานหรือการลดเงิน/เวลาได้จริง Browser ใช้ JavaScript number ส่วน Python ใช้ Decimal; การตรวจเทียบครอบคลุมค่าทดสอบที่ระบุ ไม่ได้พิสูจน์ความเท่ากันของเลขทุกความละเอียดที่ระบบทั้งสองรับได้
