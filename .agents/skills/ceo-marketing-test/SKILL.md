# Marketing test

Read [the shared local runtime contract](../bni-second-brain/references/codex-runtime.md) before work.
Reuse `data/state.json` and the selected company's accessible files; save outputs under `work/ceo/`.

Use a supported customer problem, audience, actual product/offer and source-backed proof. Separate demand evidence from assumptions.
State one test hypothesis, one variable to change, channel/format within supplied capacity and comparison/baseline if known.
Draft a concrete message and CTA without fabricated benefits, scarcity, testimonials or price commitments.
Specify proposed sample/timebox, metric with denominator, learning threshold, spend cap if supplied and stop rule.
Unknown budget stays not set. Avoid declaring a winner from an unmeasured or incomparable sample.
Deliver ready-to-review test brief and draft copy. Running ads, contacting customers, publishing or spending needs explicit scope.
No campaign platform or paid connector is required to prepare the local brief.
