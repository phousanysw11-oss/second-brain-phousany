# My Second Brain: saved local app

Reuse this saved app and brain.config.json. Its root is this learner workspace. Default local URL: http://127.0.0.1:4782 . OPEN_WINDOWS.cmd or OPEN_MAC.command at the workspace root starts Dashboard and this app together after preflight.

For a standalone start, from this directory run `node serve.mjs`. First check whether the saved local graph endpoint is already responding; do not start a duplicate or stop another app on this port. No npm installation is needed. The default sources are local context, work/notes, wiki, raw/references and .agents/skills. No external or personal memory source is selected.

Use search, open a note, follow its actual source, and use Rebuild after saving new knowledge. The initial nodes are starter method notes and skills, not completed learner business work. Keep all companion files and THIRD-PARTY-NOTICES.txt.
