# Source routing

Use the sources the person actually names for this project. No company account or dataset is preconnected.
For tasks use data/state.json; for confirmed priorities use context/priorities.md.
For performance reports, record source file/tab/range, period, unit and collection date. Blank is unknown, not zero. If data/team-data.json exists, treat it as a dated local snapshot, not live data.
Keep businesses and departments separate. Respect actual access permissions. Do not infer a gateway, Google connection or manager access from the template.
