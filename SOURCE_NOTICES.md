# Sources and licenses

## Core Seven release

My Second Brain **3.1.0-core-seven** is a smaller adaptation of the public v3.0.1 package (commit `33360aafce3daa5f95660c87188b5addf03e3128`). It retains seven unique project skills: onboard, grill-me, audit, level-up, wiki-helper, 3d-brain and open-3d-brain. Each skill is mirrored for Claude Code and Codex. The release includes zero custom agent roles.

The learner package has blank Markdown context and an empty source-linked Wiki. It contains no author's business records, learner answers or connected accounts. The local onboarding and plain-text routing adaptations are part of this release. No efficacy, business outcome or platform endorsement is claimed.

## Retained sources

- **AIS-OS:** [Nate Herk / AIS-OS](https://github.com/nateherkai/AIS-OS). Its MIT license is preserved in [AIS-OS-LICENSE.txt](AIS-OS-LICENSE.txt). The Three Ms of AI and The Four Cs of an AI OS are attributed to Nate Herk; those names are his trademarks, not original Phousany frameworks. Where the retained audit/level-up skills use these source concepts, illustrative ratios and scores are teaching examples, not learner facts or verified results. Adaptation does not imply endorsement.
- **LLM Wiki:** raw sources, synthesized Wiki, index and log structure adapted from [Astro-Han / karpathy-llm-wiki](https://github.com/Astro-Han/karpathy-llm-wiki), with a simplified local evidence-routing method. This is not the complete upstream package.
- **3D Brain:** retained optional renderer/runtime and selected skill assets from the earlier public package. Preserve [the runtime third-party notices](apps/3d-brain/THIRD-PARTY-NOTICES.txt) and the license notices within both skill copies. The release does not relicense fonts or third-party libraries.

Earlier helper skills, Dashboard assets, CEO workshop materials and custom agent roles are outside this smaller package. Existing upstream attribution and license files remain with the retained code.
