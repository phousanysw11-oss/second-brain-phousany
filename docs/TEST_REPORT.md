## Failures found and repaired

Failed Desk writes originally disabled backup; attempted edits can now be downloaded after failure. Projection failure after a committed state now returns a warning. Demo initialization rejects populated role-only/custom profiles. Calendar validation rejects impossible dates. Board packets now require scoped sources, whitelist metadata, exclude previous Board/oracle material and reject directory traversal. The affected tests were rerun and passed.

The restrictive Windows sandbox denied atomic file replacement in some disposable test folders; normal authorized Windows execution passed those tests. Initial fresh-session test setup accidentally selected the old root 3.0.1 ZIP; it was discarded as a test target and a separate clean folder received the actual preview ZIP. No user company folder was overwritten.

Nested Codex tests remain a platform limitation: no local-read/native-role runtime proof. They are not substituted with persona role-play, generic subagents, hand-written model answers or static file assertions. A CLI exit code 0 is not a passing workshop test.
